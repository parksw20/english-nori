# 영어놀이

7세(초1) 아이를 위한 **파닉스 기반 영어 학습 게임**. 자매 프로젝트 [한자놀이](../한자놀이)의 구조를
그대로 옮겼다 — 급수 사다리 자리에 **파닉스 단계**가 들어간다.

> 파닉스 단계 = 스테이지 / 단계 테스트 = 보스전 / 낱말 도감 = SRS
> 파닉스는 이미 완성된 난이도 곡선이라 **게임 밸런싱으로 순서를 건드리지 않는다.**

**공개 주소: https://parksw20.github.io/english-nori/** (폰·태블릿에서 바로 열립니다. 한 번 열면 오프라인에서도 놀 수 있어요)

현재 범위: **단계 0(알파벳 26자) → 단계 1(단모음 CVC)**, 낱말 50개 · 화면·미니게임·문장·생활 표현까지 동작

## 실행

```bash
npm install
npm run dev      # http://localhost:5310
```

집 안 태블릿·폰에서 열어 볼 때 (배포본 대신 지금 고친 것을 보려면):

```bash
npm run lan      # 0.0.0.0에 바인딩 — http://<PC의 LAN IP>:5310
```

처음 한 번은 Windows 방화벽이 물어봅니다(사설 네트워크 허용). 소리는 **크롬·엣지**에서 열어야
제대로 납니다 — 기기에 영어 음성이 없으면 듣기 문제를 글자로 대신 보여 줍니다.

## 배포

`main`에 밀면 GitHub Actions가 **테스트 → 빌드 → Pages 배포**를 한다(`.github/workflows/deploy.yml`).
**테스트가 실패하면 배포되지 않는다** — 데이터가 깨진 채로 나가면 아이가 못 읽는 낱말이나
못 깨는 판을 만나기 때문이다.

- 공개 주소: <https://parksw20.github.io/english-nori/>
- 저장소: <https://github.com/parksw20/english-nori>
- `vite.config.ts`의 `base: './'` 덕에 Pages 하위 경로·로컬 preview·파일 열기가 같은 산출물로 동작한다.

### PWA (오프라인)

한 번 열면 서비스 워커가 자산을 캐시해 인터넷 없이도 놀 수 있다. 홈 화면에 추가하면 앱처럼 뜬다.

- **HTML은 네트워크 우선, 해시 자산만 캐시 우선** — 반대로 하면 배포 뒤 낡은 index.html이 캐시에서
  나오고 그 안의 자산이 404가 되어 흰 화면이 뜬다(한자놀이에서 겪고 고친 그대로).
- **개발 서버(localhost)에서는 등록하지 않는다** — 고친 코드가 아니라 캐시된 옛 코드를 보게 된다.
  예전에 등록된 것이 있으면 스스로 해제한다.
- 발음 채점(SpeechRecognition)은 네트워크가 필요해서 **오프라인에서는 저절로 꺼진다**(녹음 비교만 된다).

```bash
npm test
```

데이터 무결성 39항목 + 사천성 14항목 + 카드·보상 16항목 + 말하기 채점 7항목 (총 76항목). **데이터를 손으로 고쳤으면 이걸 먼저 돌린다.**

## 어휘 기준

Cambridge English **Pre A1 Starters** A–Z 어휘 목록 (공식 PDF에서 추출, `src/data/starters.json`, 표제어 491개).
출처: [Pre A1 Starters Word list picture book](https://www.cambridgeenglish.org/images/351849-pre-a1-starters-word-list-2018.pdf)

- 낱말은 원칙적으로 이 목록 안에 있어야 한다 (`source: 'starters'`). 테스트가 강제한다.
- 숫자 낱말(ten·six)은 A–Z 목록에 없지만 공식 "Letters & numbers" 항목이 **1~20을 출제 범위로 명시**한다 → `source: 'number'`
- 목록 밖 낱말은 `source: 'phonics'` + `PHONICS_EXTRA`에 **이유를 적어야** 하고, 단계별 30% 상한이 걸린다.
  현재 7개: queen·umbrella·van(Starters에 q·u·v로 시작하는 아이용 낱말이 없다), pig·hot·pot·fox(단모음 o의 CVC가 box·dog뿐).
- ⚠️ 공식이 **총 낱말 수를 명시하지 않아** 개수 대조는 **미확정**이다. 대신 같은 PDF를 두 가지 방식으로
  독립 추출해(레이아웃 모드·읽기순 모드) 합집합을 쓰고, 의심 항목은 원문에서 개별 확인했다.

## 파닉스 사다리

| 단계 | 마을 | 배우는 것 | 낱말 |
|---|---|---|---|
| 0 | 알파벳 마을 | a~z 26자의 대표 소리 | 26 (대표 낱말) |
| 1 | 단모음 마을 | 단모음 CVC (a·e·i·o·u) | +24 → CVC 출제 풀 32 |
| 2~6 | (예정) | 쌍자음 → 두글자소리 → 마법의 e → 긴모음 → r모음 | — |

단계 2 이후는 낱말이 없지만 **그래핌표에는 이미 있다**(`src/data/phonics.ts`). `sock`의 `ck`가 단계 2라는 것을
표가 알고 있어야, 단계 1 낱말에 sock이 섞여 든 것을 테스트가 잡아낼 수 있다.

## 단계 테스트 (보스전)

| 단계 | 문제 구성 | 총문항 | 합격 |
|---|---|---|---|
| 0 | 소리→글자 8 · 글자→낱말 6 · 그림→첫글자 6 | 20 | 14 |
| 1 | 듣고 낱말 8 · 그림→낱말 7 · 빠진 모음 5 | 20 | 14 |

합격선은 전 단계 70%. 구성표(`src/exam.ts`의 `EXAMS`)가 정본이고, 합계가 총문항과 어긋나면
**앱이 뜨는 순간 터진다**. 밸런싱으로 문항 수를 건드리지 않는다.

한 시험 안에서는 **같은 낱말·글자를 두 번 묻지 않는다.** 문항을 매번 독립적으로 뽑으면
20문항 중 평균 5.3개가 겹치고(최악 10개) `letter-word`는 정답이 대표 낱말로 고정돼 있어
**완전히 같은 문제**가 두 번 나온다. 그래서 시험 하나당 '장부'(`Ledger`)를 두고 안 쓴 것부터 뽑으며,
글자와 낱말을 함께 적어 "ball을 듣고 b 고르기"와 "🏀ball의 첫 글자 고르기"가 같이 나오는 것도 막는다.
테스트가 30판을 세어 중복 0을 확인한다.

## 놀이 방식

- **지도** — 마을(파닉스 단계)을 고른다. 그 마을 시험에 합격해야 다음 마을이 열린다.
- **오늘의 놀이** — 이 앱의 본체. 새 낱말 4개 + 복습 8개 = 12문제로 **끝이 정해져 있다.**
  끝나면 스티커 한 장(하루 한 장). 7세는 무한히 이어지는 화면에서 스스로 그만두지 못한다.
- **미니게임 7종 + 말하기**
  - `소리 사냥` — 소리를 듣고 글자/낱말 고르기 (10문제)
  - `낱말 만들기` — 그림을 보고 글자 타일을 순서대로 놓기 (6낱말). 틀린 자리를 알려주지 않는다(알려주면 찍기가 된다)
  - `낱말 요격` — 한자놀이의 「독음 요격」을 옮긴 것. 낱말이 떨어지고 **읽어서 그림을 맞힌다**.
    보기는 최소대조쌍이 먼저 와서(cat이 떨어지면 🐱🎩🦇🎒) 첫소리·모음을 구별해야 맞힌다.
    위에서 맞힐수록 점수가 높고(10~30점), 하트 3개를 다 쓰면 끝난다
  - `사천성` — 낱말 타일과 그림 타일을 **꺾임 2번 이내의 길로 이어 없앤다**.
    판 크기를 고를 수 있다: **작은 판 4×6(12쌍) · 중간 판 6×6(18쌍) · 큰 판 8×8(32쌍)** — 마지막에 고른 크기를 기억한다.
    낱말은 **판 크기에 따라 늘어난다**(낱말마다 두 쌍: 12쌍→6낱말, 18쌍→9낱말, 32쌍→16낱말).
    시간 제한이 없고, **길이 다 막히면 안내창을 띄우고 알아서 섞는다.**
    규칙은 `src/shisen.ts`에 순수 함수로 있고 **테스트가 크기마다 판 100개를 끝까지 풀어 본다** —
    못 깨는 판을 아이에게 주지 않기 위해서다
  - `그림 짝맞추기` — 낱말 카드 ↔ 그림 카드 6쌍 (기억력)
  - `문장 놀이` — **듣기 → 어순 → 따라 말하기** 세 단계. 문장은 손으로 적지 않고 **틀 + 낱말**로 만든다
    (`I see a %n.`), 그래서 낱말이 늘어도 문장을 다시 쓰지 않는다. 문장에 쓰이는 낱말은 전부
    아이가 읽을 수 있는 것(CVC ∪ sight words)임을 테스트가 강제한다
  - `생활 표현` — 유치원 생활에서 실제로 쓰는 말 51문장 / 7장면(인사·부탁·기분·놀이·교실·밥·도움).
    **읽기를 요구하지 않는다** — `Can I go to the bathroom?`은 읽으려면 단계 6까지 가야 하지만
    오늘 당장 필요한 말이다. 통째로 듣고 따라 말하고, 채점하지 않는다
  - `말하기` — 녹음해서 원어민 소리와 번갈아 듣기 + (가능하면) 발음 채점

## 말하기 채점 — 낱말과 문장을 다르게 본다

| | 낱말 | 문장·생활 표현 |
|---|---|---|
| 판정 | 목표 낱말이 들리면 통과 (편집거리 ≤1) | **내용어가 몇 개 들렸는지** (기본 6할, 생활 표현 5할) |
| 기능어 | — | `a·the·is·I` 등은 **세지 않는다** (아이 발음에서 뭉개지고 인식기도 흘린다) |
| 피드백 | 통과/재시도 | **들린 낱말을 낱말별로 표시** (초록=들림, 파랑=안 들림) |
| 막힘 방지 | 3번이면 통과 | 3번이면 통과 |

처음에는 문장에 채점을 넣지 않았다("문장은 인식률이 더 낮다"). **근거가 약한 판단이었다** —
인식기는 문맥(언어 모델)을 쓰기 때문에 낱말 하나보다 문장을 더 잘 잡는 경우가 많다.
진짜 문제는 인식률이 아니라 **채점 방식**이었다: 문장을 통째로 대조하면 아이는 거의 못 넘는다.
"다시 해"보다 "bus는 들렸어, hat을 한 번 더"가 아이에게 쓸모 있으므로 낱말별로 보여준다.

## 문장과 생활 표현 — 두 갈래를 나눈 이유

| | 읽는 문장 (`TEMPLATES`) | 생활 표현 (`PHRASES`) |
|---|---|---|
| 목적 | 파닉스로 읽어 보기 | 오늘 쓸 말을 통째로 익히기 |
| 어휘 | 배운 CVC + sight words **만** | 생활 기준 (읽기 제약 없음) |
| 만드는 법 | 틀 + 낱말 계산 | 손으로 적은 51문장 |
| 채점 | 듣기·어순·말하기 모두 채점 | 말하기 채점(기준 0.5) |
| 검사 | **모든 낱말이 읽을 수 있어야** 통과 | 읽기 낱말 목록에 새어 들지 않는지만 확인 |

한국어 뜻의 **조사는 받침을 보고 고른다**(`%k{을/를}`) — "버스을"·"승합차을"이 나오지 않게.
낱말 요격에서 조사를 붙였다가 "가방 였어"가 나와 기호로 피했는데, 문장 뜻은 조사 없이 쓸 수 없어서
받침 판정 함수(`hasFinalConsonant`)를 만들었다. 결과 문장을 그대로 대조하는 테스트가 10가지 조합을 검사한다.
- **낱말 도감** — 익힌 낱말이 흑백 → 색 → 또렷 → 반짝 → 금카드로 자란다. 카드를 누르면 읽어 준다.
  맨 위에 **🔤 ABC 알파벳** 판이 있다 — 26자를 **대문자·소문자 짝**(`A a`)으로 늘어놓고 누르면 읽어 준다.
  도감의 낱말은 전부 소문자인데 아이가 바깥에서 만나는 글자는 대문자가 섞여 있어(이름표·간판),
  같은 글자의 두 모습을 한 카드에 붙여 둬야 둘이 한 글자임을 안다.
  보기가 둘이다: **전체**(ABC 판 + 낱말 전부)와 **알파벳별**(a~z 탭).
  알파벳 탭에는 그 글자의 카드(글자·이름·소리·대표 낱말)가 먼저 나오고 그 글자로 시작하는 낱말이 이어진다.
  **알파벳 탭을 누르면 그 글자를 읽어 준다**(a → "에이") — 화면만 바뀌면 아이가 글자 이름을 배울 수 없다.
  누르는 것이 곧 듣는 것이어야 한다(「전체」는 보기 이름이라 읽지 않는다).
  낱말이 없는 글자(q·v)도 탭을 지우지 않는다 — 알파벳은 26자를 다 배우는 것이고,
  빈 탭이 있어야 "여기는 아직 낱말이 없구나"를 아이가 안다. `x`는 첫소리로 쓰지 않으므로
  **그 글자가 든 낱말**(box)을 보여주고 「끝소리」라고 적는다.
  **한 번 올라간 단계는 되돌아가지 않는다**(틀렸다고 모은 것을 빼앗지 않는다). 복습이 밀리면 점선으로 표시.
- **부모님 화면** — 소리별 진행, 자주 틀리는 낱말, 놀이 기록, 시험 기록. **채점하지 않은 것은 "미채점"이라고 밝힌다.**
- **성취 타일** — 지도와 마을 화면에 목표 막대(이 단계 낱말을 몇 % 익혔나)와 타일 4개
  (배운 낱말 n/전체 · 오늘 복습할 것 · 잘 익은 낱말 · 수료증). 분모가 보이면 채우고 싶어진다.
- **놀이 방법 📘** — 규칙을 코드에만 두면 아이는 규칙을 모르는 채로 논다. 특히 카드를 어떻게 받는지,
  왜 판이 저절로 섞이는지는 화면만 봐서는 알 수 없다 → 9개 블록으로 적어 둔다.
- **설정 ⚙️** — 테마(기기 설정/밝게/어둡게) · 효과음 크기 · 목소리와 속도 · 낱말 요격 속도 가중 ·
  기록 저장/불러오기 · 지우기 비밀번호. **어른이 보는 화면**이라 글씨가 작고 조용하다.

## 글자 카드와 단어장 📒

한자놀이의 「한자 카드」를 옮긴 것인데, 영어에서는 **글자 카드**가 된다: `c`+`a`+`t` → cat.
그래서 보상 자체가 **스펠링 연습**이다 — 소리로 아는 낱말을 글자로 조립해 봐야 쓰기로 넘어간다.

| 놀이 | 카드 |
|---|---|
| 🌟 오늘의 놀이 | 다 하면 2장 |
| 👂 소리 사냥 | 4문제 맞힐 때마다 1장 |
| 🧩 낱말 만들기 | 한 판 1장 (전부 한 번에 맞히면 1장 더) |
| 🚀 낱말 요격 | 100점마다 1장 |
| 🀄 사천성 | 판을 다 비우면 2장 (8×8은 3장) |
| 🃏 그림 짝맞추기 | 한 판 1장 |
| 🏅 마을 시험 | 처음 합격 10장 + **합격선~만점 구간에 최대 10장** (만점 20장) |

- **카드를 누르면 그 글자를 읽어 준다** (`c` → "씨"). TTS에 글자 하나를 주면 음소가 아니라 **글자 이름**이
  나오는데, 다른 곳에서는 그게 문제였지만 여기서는 그것이 맞다 — 스펠링은 "씨-에이-티"처럼 이름으로
  부르며 조립하는 것이기 때문이다. 가진 카드·만들기 화면·교환 고르기 모두 같다.
- 낱말이 완성되면 마지막 글자를 읽고 **이어서** 낱말을 통째로 들려준다(겹치면 둘 다 안 들린다).
  아이가 그 사이에 다음 카드를 누르면 앞서 예약된 소리는 스스로 그만둔다(`voiceTurn`).
- 카드는 **황금카드** 양식으로 그린다(한자놀이와 같은 모양: 금테 + 금색 글씨 + 장수).
  이모지 🎴를 쓰지 않는 이유: 그건 화투 카드라 이 앱과 무관하고, 무엇보다 **어떤 글자를 받았는지 안 보인다.**
  받은 카드를 그대로 그려 주면 그 글자를 읽게 되어 짧은 연습이 된다.
- 카드는 **아무렇게나 주지 않는다**: ①조금만 더 모으면 완성되는 낱말의 모자란 글자 → ②그 단계 낱말의 글자
  → ③알파벳. 그래야 받은 카드가 바로 낱말이 되어 "모으는 재미"가 실제로 굴러간다.
- 시험 보상을 0점부터 나누지 않는 이유: 그러면 합격선만 넘겨도 덤의 7할을 받아 만점의 의미가 사라진다
  (한자놀이에서 배운 것). 구간 분배는 테스트가 `0,1,3,5,6,8,10`으로 못 박아 둔다.
- 쓸 데 없는 카드 5장 → 원하는 글자 1장으로 바꾼다. 바꿀 때는 **낱말에 안 쓰이는 카드부터** 낸다.

## 사천성 조작 규칙

- 짝이 아니거나 길이 막혀 **실패하면 선택을 모두 지운다.** 카드 하나가 켜져 있으면 아이는
  "아직 고르는 중"으로 읽어 다음 한 번이 헛클릭이 된다.
- 기회 5번은 **짝이 아닌 것을 고를 때만** 줄어든다(길 막힘·자동 섞기는 아이 잘못이 아니다).

## 말하기 (음성인식)

**기본은 녹음이다.** MediaRecorder로 아이 목소리를 녹음해 원어민 TTS와 번갈아 들려준다 —
채점이 없어도 연습이 성립하고 오프라인·모든 브라우저에서 된다.
받아쓰기 채점(`SpeechRecognition`)은 **Chrome/Edge + 네트워크**가 있을 때만 보너스로 붙는다.

채점은 관대하다: 받아쓴 말에 목표 낱말이 있거나 편집거리 ≤1이면 통과, **세 번 시도하면 무조건 통과**.
7세 목소리 인식률은 낮아서 엄격하게 하면 맞게 말했는데도 막히고, 그러면 놀이가 그 자리에서 끝난다.

## 그림으로 물어도 되는 낱말 (`abstract` 표시)

🐘를 보여주고 `big`을 고르라는 문제는 **답을 알 방법이 없는 문제**다 — 아이는 elephant를 떠올린다.
🔥는 불이고 뜨거움이 아니며, 🪑는 의자이고 앉기가 아니다. 그래서 그림으로 알아볼 수 없는 낱말에는
`abstract: true`를 붙이고 **그림이 곧 문제인 곳에서 뺀다**.

현재 10개: `zoo`🦁(사자) `man`🧑(사람) `mat`🟫 `men`👬(man과 구별 불가) `pet`🐕(dog와 겹침)
`big`🐘 `sit`🪑 `hot`🔥 `fun`😄 `rug`🧶

| 쓰는 곳 | abstract 낱말 | 이유 |
|---|---|---|
| 그림→낱말, 그림→첫글자, 짝맞추기, 사천성 | ❌ 제외 | 그림이 문제 자체다 |
| 듣고→낱말, 빈칸 모음, 듣고→첫글자 | ⭕ 그대로 | 소리가 문제라 그림은 거들 뿐 |
| **오답 보기(글자)** | ⭕ 그대로 | 🐷에 big·bag·six가 붙으면 소리를 구별해야 하는 좋은 문제가 된다 |
| 글자→대표 그림(letter-word) | ⭕ 대표 낱말이면 | "z 하면 배운 그림은?"이라 🦁=zoo가 정답이 맞다 |
| 낱말 도감 | ⭕ 그대로 | 그림과 뜻을 함께 보여주므로 문제없다 |

낱말을 버리는 것이 아니라 **묻는 방식만 가린다.** 표시를 빼먹는 실수는 테스트가 잡는다
(그림 문제를 30판 생성해 abstract 낱말이 그림으로 나오는지 검사).

## 설계에서 지킬 것 (7세 기준)

1. **오디오가 1급 시민** — 영어 글자도 한글 안내문도 못 읽는 상태가 기본값. 모든 화면이 그림+소리로 성립해야 한다.
2. **오답에 벌을 주지 않는다** — 빨간 X 대신 정답 소리를 다시 들려주고 넘어간다.
3. **하루 10~15분** — 새 낱말 4~6개 + 복습 8~10개 + 미니게임 1판 → 스티커 1장. 무한 플레이를 만들지 않는다.
4. **알 수 없는 그림으로 묻지 않는다** — 🐘를 보고 big을 맞히라고 하지 않는다(위 `abstract` 표).
5. **기록은 보이는 곳에 둔다** — 게임 버튼에 최고 기록을 적는다. 따로 기록 화면을 만들면 7세는 찾아가지 않는다.
6. **못 읽는 낱말을 읽으라고 하지 않는다** — 알파벳 단계의 apple은 소리를 기억시키는 그림일 뿐이다.
   읽기를 요구하는 문제에는 `decode` 표시가 붙고, 그 문제에만 "그 단계까지 배운 글자" 규칙이 적용된다.

- 일부러 **전부 틀린 경로**도 확인 → 불합격·수료증 없음·5분 쿨다운 안내

- 소리 사냥 10/10, 낱말 만들기 6/6, 짝맞추기 6쌍(빠른 연타 포함), 도감 카드 단계 표시, 부모 화면 표

  사천성·짝맞추기 각 6판의 타일에도 abstract 낱말 없음
- **중복 문항** — 시험 50판 × 2단계에서 똑같은 문제 0개, 같은 낱말 두 번 묻기 0개.
  실제 시험 화면을 끝까지 풀어 20문항이 전부 다른 낱말임을 확인(고치기 전 시뮬레이션은 평균 5.3개 중복)
- **카드·단어장** — 소리 사냥 10/10 → 카드 2장 안내창(`a t`), 단어장에서 cat을 만들어 카드 0장·단어장 1개 확인.
  교환·보상 구간은 단위 테스트로 못 박음
- **글씨 대비 전수 측정** — 두 테마 × 9화면의 모든 글씨에 WCAG 대비를 계산해 미달 0건.

- **다크모드** — 세 상태 실측: 밝게 강제 `#fff6e5` / 어둡게 강제 `#131a2b` / 기기 설정은 속성 없이 따라감.

## 알려진 제약

- 낱말이 **50개**뿐이다. Pre A1 Starters 목록 안에서 단모음 CVC를 뽑으면 40개(고유명사·기능어 포함),
  그림으로 낼 수 있는 것은 25개가 한계다. 단계 2(쌍자음·이중자음)를 열면 sock·duck·frog·clock 등이
  한꺼번에 들어와 크게 늘어난다.
- 음소 단독 발음(/æ/, /sh/)은 TTS로 부정확하다 → 낱말 안에서 들려주는 방식이 기본(`tts.blend`).
  음소 단독 오디오 파일이 필요한지는 실기기에서 확인한 뒤 결정한다. **미확정**
- **끝소리 x**는 첫소리 문제에 나올 수 없어(box를 들려주고 답이 x일 수는 없다) 시험에서는 보기로만 등장한다.
  끝소리를 묻는 문제 유형은 아직 없다.
- 영어 음성이 없는 기기에서는 듣기 문제가 성립하지 않아 **들려줄 말을 글자로 대신 보여준다**(+ 부모용 안내).
  근본 해결은 음성이 있는 기기에서 놀는 것이다.
- PWA(오프라인)·GitHub Pages 배포는 아직 붙이지 않았다(P4).
